PUBLICAÇÃO SUGERIDA NO GITHUB PAGES
1. Crie um repositório público chamado: avaliacao-ferramentas-web
2. Envie os quatro arquivos acima para a raiz do repositório.
3. No GitHub, abra Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha a branch main e a pasta / (root), depois clique em Save.
6. Aguarde a publicação.

Com o usuário jcespinato e esse nome de repositório, o endereço esperado será:
https://jcespinato.github.io/avaliacao-ferramentas-web/

Importante: o endereço só ficará acessível depois que os arquivos forem enviados e o GitHub Pages for ativado.
