Projeto acadêmico em HTML e CSS

Tecnologia de forma simples

Este site demonstra a criação de páginas web simples, com navegação entre arquivos HTML, organização semântica do conteúdo e estilização por CSS.

Ver produtos

Sobre o projeto

A proposta apresenta uma pequena vitrine de tecnologia. O conteúdo foi produzido manualmente, sem uso de páginas prontas de aplicativos ou construtores automáticos.

HTML semântico

Uso de cabeçalho, navegação, conteúdo principal, seções, artigos e rodapé.

Navegação

Links entre três páginas independentes: início, produtos e contato.

Responsividade

Layout adaptado para telas menores por meio de regras simples de CSS.

Desenvolvido para fins acadêmicos por João Carlos de Souza Espinato.
